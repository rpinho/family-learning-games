# Pond journey preview

An original SVG picture-book page: counting builds a five-leaf raft; two gates route a boat to a map. It mounts through the Book lifecycle, with a synthetic review chapter and no saved progress. Production chapter generation is unchanged. This idea branch is for review only.

The 20-second mono AAC water bed is original, deterministic filtered noise (seed 723), with a periodic envelope and a -20 LUFS loudness target. It is 163 KB, loads on a gesture, ducks during recorded narration and pauses when hidden. Harp-like feedback is synthesized locally; neither sound was sampled from another app. No new runtime library or remote asset is needed.

The optional `pond-companions.json` in the preview's data folder maps `count` and `flow` to local artwork URLs and `modes` to account choices. The public fallback is an original bird. Never publish a household mapping or asset. The recorded review prompts are included in the normal release voice-line builder.
